# 实验1 Android开发基础

## 一、实验目的

1. 熟悉 Android Studio 的安装与基本配置
2. 掌握创建 Android 工程的基本流程
3. 学习将 Android 项目同步至 Gitee/GitHub 远程仓库

|------|-----------|
| 操作系统 | Windows |
| Android Studio | 2026.1.3 |
| JDK | 21（Embedded JBR） |
| Android SDK | API 37 |

| 开发语言 | Java |

## 三、实验内容与步骤

### 3.1 安装 Android Studio

1. 从官网下载 Android Studio 安装包
2. 运行安装程序，选择安装路径，完成安装
3. 首次启动时，配置 SDK 路径（`D:\Eason\Android_data`），Studio 会自动下载 SDK 组件

> **注意事项**：国内网络环境下，首次启动下载 SDK 可能较慢，需耐心等待。

### 3.2 创建第一个 Android 工程

1. 打开 Android Studio，点击 **New Project**
2. 选择模板：**Phone and Tablet → Empty Views Activity**（带 Views，使用传统 View 体系）
3. 配置项目信息：

| 配置项 | 值 |
|--------|-----|
| Project Name | MyFirstApp |
| Package Name | com.example.myfirstapp |
| Save Location | D:\Eason\AndroidProjects\MyFirstApp |
| Language | Java |
| Minimum SDK | API 24（Android 7.0） |
| Build configuration | API 37 |

4. 点击 **Finish**，等待 Gradle 同步完成

### 3.3 解决 Gradle 同步问题

由于国内网络环境，默认的 Gradle 下载地址和 Maven 仓库无法正常访问，需要更换镜像源。

#### 3.3.1 更换 Gradle 下载镜像

修改 `gradle/wrapper/gradle-wrapper.properties`：

```properties
# 修改前
distributionUrl=https\://services.gradle.org/distributions/gradle-9.5.0-bin.zip

# 修改后（腾讯云镜像）
distributionUrl=https\://mirrors.cloud.tencent.com/gradle/gradle-9.5.0-bin.zip
```

#### 3.3.2 更换 Maven 仓库镜像

修改 `settings.gradle.kts`，在 `pluginManagement` 和 `dependencyResolutionManagement` 的 repositories 中添加阿里云镜像：

```kotlin
pluginManagement {
    repositories {
        maven { url = uri("https://maven.aliyun.com/repository/google") }
        maven { url = uri("https://maven.aliyun.com/repository/public") }
        maven { url = uri("https://maven.aliyun.com/repository/gradle-plugin") }
        google()
        mavenCentral()
        gradlePluginPortal()
    }
}

dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
    repositories {
        maven { url = uri("https://maven.aliyun.com/repository/google") }
        maven { url = uri("https://maven.aliyun.com/repository/public") }
        google()
        mavenCentral()
    }
}
```

#### 3.3.3 配置 JDK

1. 打开 `File → Project Structure → SDK Location`
2. JDK location 选择 **Embedded JDK**（Android Studio 自带的 JBR，版本为 JDK 21）
3. 点击 Apply → OK

#### 3.3.4 重新同步

点击工具栏的大象图标 **Sync Project with Gradle Files**，Gradle 同步成功：

```
BUILD SUCCESSFUL in 5m 10s
33 actionable tasks: 33 executed
```

### 3.4 配置 .gitignore

Android 项目需要忽略编译产物、IDE 配置、本地 SDK 路径等文件。根目录 `.gitignore` 配置如下：

```gitignore
# Built application files
*.apk
*.aab
*.dex

# Gradle files
.gradle/
build/

# Local configuration file
local.properties

# Android Studio generated files
.idea/
*.iml

# External Native build
.externalNativeBuild/
.cxx/

# OS files
.DS_Store
Thumbs.db

# Log files
*.log

# Package Files
*.jar
*.zip
```

### 3.5 同步至 Gitee 远程仓库

1. **创建远程仓库**：在 Gitee 上新建空仓库 `my-first-app`，不勾选任何初始化选项
2. **初始化本地 Git 仓库**：
   ```powershell
   cd D:\Eason\AndroidProjects\MyFirstApp
   git init
   ```
3. **添加文件并提交**：
   ```powershell
   git add -A
   git commit -m "feat: first Android project - MyFirstApp"
   ```
4. **关联远程仓库并推送**：
   ```powershell
   git remote add origin git@gitee.com:yx0331/my-first-app.git
   git push -u origin master
   ```

推送成功，输出如下：

```
branch 'master' set up to track 'origin/master'.
To gitee.com:yx0331/my-first-app.git
 * [new branch]      master -> master
```

## 七、问题与解决

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| Gradle sync failed，UnknownHostException | 国内网络无法访问 services.gradle.org 和 maven.google.com | 更换为腾讯云 Gradle 镜像和阿里云 Maven 镜像 |
| Project JDK is not defined | 未配置 JDK 路径 | 在 Project Structure 中选择 Embedded JDK |
| GitHub 无法访问（机器人验证） | 代理 IP 被 GitHub 反爬虫机制拉黑 | 改用 Gitee，国内直连稳定 |
| Gitee 仓库 404 not found | 仓库名大小写不匹配，Gitee 自动转为小写加短横线 | 使用 `my-first-app` 而非 `MyFirstApp` |

## 八、实验心得

通过本次实验，完成了 Android 开发环境的搭建和第一个工程的创建。实验过程中遇到了国内网络环境下 Gradle 无法正常下载的问题，通过更换国内镜像源得以解决。这让我意识到在国内进行 Android 开发，配置合适的镜像源是必要的前置步骤。同时，正确配置 `.gitignore` 对于保持远程仓库整洁也非常重要。实验为后续 Android 开发课程打下了基础。
